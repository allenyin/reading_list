# Jekyll to Eleventy (11ty) Migration Guide

Generated by Cursor

## Overview
This document outlines the steps to migrate from Jekyll to Eleventy (11ty) for the reading list project. The migration will enable automatic tag generation and LaTeX equation rendering without manual HTML file creation.

## Why Migrate to Eleventy?
- **Automatic Tag Generation**: No more manual HTML files for each tag
- **Better LaTeX Support**: Native support for math equations with `$$...$$` blocks
- **Faster Build Times**: Node.js-based build system
- **Modern JavaScript Ecosystem**: Access to npm packages and modern tooling
- **Simplified Configuration**: Single `.eleventy.js` config file
- **Flexible Date Handling**: Extract dates from front matter or filenames
- **Permalink System**: Easy cross-referencing between posts using post names
- **Smart Collections**: Separate collections for existing vs. future posts

  function generatePermalink(post) {
    // Check for existing permalink override
    if (post.data.permalink) {
      return post.data.permalink;
    }

    // Then, create a "clean" slug by removing the date prefix if it exists.
    const cleanSlug = post.fileSlug.replace(/^\d{4}-\d{2}-\d{2}-/, '');

    // Finally build the consistent url
    return `/posts/${cleanSlug}/`;

#### 6.3. Update `.eleventy.js` to add tag page generation:
```diff
  // Collection for posts by tag
  eleventyConfig.addCollection("postsByTag", function(collectionApi) {
    const posts = collectionApi.getFilteredByGlob("_posts/**/*.md");
    const postsByTag = {};
    
    posts.forEach(post => {
      if (post.data.tags) {
        post.data.tags.forEach(tag => {
          if (!postsByTag[tag]) {
            postsByTag[tag] = [];
          }
          postsByTag[tag].push(post);
        });
      }
    });
    
    return postsByTag;
  });
+ 
+ // Generate tag pages automatically
+ eleventyConfig.addPassthroughCopy("tags");
```

**How Tag Page Generation Works:**

The tag pages are automatically generated using Eleventy's collection system:

1. **`collections.tags`** - Contains all unique tags from your posts
2. **`collections.postsByTag`** - Maps each tag to an array of posts  
3. **`tags.njk`** - Uses `collections.tags` to display all available tags
4. **`_layouts/tagpage.njk`** - Uses `collections.postsByTag[tag]` to show posts for each tag

No manual HTML files are needed - Eleventy handles everything automatically!

Also delete the `sidebar.html` because it's redundant with `tags.njk` and `tagpage.njk`, which shows posts organized for all tags, and posts organized for a single tag, respectively.

### 7. Create Tag Generation Script
Create `generate-tags.js`:

```javascript
const fs = require('fs');
const path = require('path');

// This will be handled automatically by Eleventy, but you can use this for testing
function generateTagPages() {
  const postsDir = '_posts';
  const tagsDir = 'tags';
  const posts = fs.readdirSync(postsDir).filter(file => file.endsWith('.md'));
  
  const tagMap = {};
  
  posts.forEach(postFile => {
    const content = fs.readFileSync(path.join(postsDir, postFile), 'utf8');
    const frontMatter = content.match(/^---\n([\s\S]*?)\n---/);
    
    if (frontMatter) {
      const yaml = frontMatter[1];
      const tagsMatch = yaml.match(/tags:\s*\n\s*-\s*(.+)/g);
      
      if (tagsMatch) {
        tagsMatch.forEach(tagLine => {
          const tag = tagLine.replace(/tags:\s*\n\s*-\s*/, '').trim();
          if (!tagMap[tag]) {
            tagMap[tag] = [];
          }
          tagMap[tag].push(postFile.replace('.md', ''));
        });
      }
    }
  });
  
  // Create tag directory if it doesn't exist
  if (!fs.existsSync(tagsDir)) {
    fs.mkdirSync(tagsDir);
  }
  
  // Generate tag pages
  Object.keys(tagMap).forEach(tag => {
    const tagPage = `---
layout: tagpage
tag: ${tag}
---

{% set posts = collections.postsByTag["${tag}"] %}
{% include "tagpage_content.html" %}
`;
    
    fs.writeFileSync(path.join(tagsDir, `${tag}.html`), tagPage);
  });
}

if (require.main === module) {
  generateTagPages();
}

module.exports = { generateTagPages };
```

#### 10.2. Create Deployment Workflow
Create `.github/workflows/deploy.yml`:

```yaml
name: Deploy to GitHub Pages

on:
  push:
    branches: [ main ]

jobs:
  build-and-deploy:
    runs-on: ubuntu-latest
    
    steps:
    - name: Checkout
      uses: actions/checkout@v2
      
    - name: Setup Node.js
      uses: actions/setup-node@v2
      with:
        node-version: '18'
        
    - name: Install dependencies
      run: npm install
      
    - name: Build site
      run: npm run build
      
    - name: Deploy to GitHub Pages
      uses: peaceiris/actions-gh-pages@v3
      with:
        github_token: ${{ secrets.GITHUB_TOKEN }}
        publish_dir: ./_site
```

1. Go to your repository on GitHub

3. **Source**: Select "GitHub Actions"

## Troubleshooting

- **Node.js version too old**: Eleventy 2.0 requires Node.js v14+. Use nvm to upgrade: `nvm install --lts`
- **Math not rendering**: Using `markdown-it-mathjax3` instead of `markdown-it-katex` for security
- **Tags not generating**: Check the collections configuration in `.eleventy.js`
- **Layouts not working**: Verify Nunjucks syntax and file paths
- **Assets not copying**: Ensure `addPassthroughCopy` is configured correctly
- **Package conflicts**: Clean install with `rm -rf node_modules package-lock.json` then `npm install`
